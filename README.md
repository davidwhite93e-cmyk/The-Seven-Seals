# The Seven Seals

Production repository for a narrative-first Twine (SugarCube)
interactive novel.

## Team Roles

-   Creative Director: Story, systems, continuity, reviews
-   Implementation Lead: Twee/SugarCube implementation
-   Executive Producer: Final decisions and priorities

## Development Workflow

1.  Update Game Bible.
2.  Write Chapter Specification.
3.  Implement Scene Package.
4.  QA & Review.
5.  Update Mystery Ledger and Changelog.
